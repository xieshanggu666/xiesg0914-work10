# 霜脊档案 · FROSTSPINE LEDGER

一款以极地科考站为背景的**资源决策冒险游戏**。单文件 HTML，无任何依赖，
浏览器直接打开 `index.html` 即可游玩（也可 `python3 -m http.server` 后访问）。

## 背景

2026 年春，南极沿岸的**霜脊站**。你带领四人小队执行第 74 考察季最后阶段任务：
极昼将尽，补给只够支撑 14 天，通信窗口稀少且短暂。每一次外出都可能带回
改写古气候记录的冰芯，也可能遭遇白化天、冰裂隙与设备故障。
游戏不设"标准答案"——科学价值与安全撤离之间的取舍由你决定，
最终生成一份**完全由实际选择构成的科考档案**。

## 每日循环（4 个阶段）

1. **晨间简报**：查看苏晓结合气象传感器给出的天气预报（含信度，实际天气会偏差）、
   今日是否有通信窗口、撤离接应状态。
2. **任务规划**：
   - 在 5 个采样点间选择（陆缘冰架 → 蓝冰走廊 → 风化峰 → 冰下湖 → 内陆异常点），
     后两个高价值点分别有**设备 / 前置发现**门槛；
   - 派出 2–3 人，必须留 1 人守站；
   - 选择**标准 / 加重配额**（多花补给，减少途中体力消耗、提振士气）；
   - 选择**标准流程 / 激进深挖**（样本更多更好，但额外消耗体力与钻机，并有受伤、塌孔风险）；
   - 暴风雪天可改为**留站实验室日**：整理已有样本（价值 +25%）、全员恢复。
3. **野外行动**：去程与返程各触发若干**风险事件节拍**（冰裂隙、白化阵风、
   雪地车故障、帝企鹅、极光、规律低频信号、队内摩擦、前人补给点……），
   每个事件都有取舍选项；抵达后按**队员专长 × 体力 × 意志**结算采样；
   返程再按低温、能见度、设备状况"算一次账"，白化天还可能遗失样本。
4. **站内夜晚**：2 个行动点，用于轮班休息、检修设备（老魏在站效果更好）、
   医官处置（苏晓在站效果更好）、队务会议（恢复士气）。
   **通信窗口**（第 2/5/8/12 日，信号强度不同）内只能上行一条信息：
   - 上行科学数据（在后方数据库建立"入库水位"，万一站点失联可保住部分成果）；
   - 请求补给空投（信号越准，收获越多）；
   - 请求撤离（接应 2 日后抵达，提前收场，期间必须守住全员生存）。

## 核心系统

- **队员**：林峥（地质/队长）、苏晓（气象/兼职医官）、老魏（机械/向导）、
  何知遥（冰川/新人）。每人有五项技能、体力（0–100）、意志（0–100）、
  轻伤/重伤状态与心理描述。体力与意志直接影响检定效率；重伤未愈每夜可能恶化。
- **设备**：燃油加热器（夜间损耗，过低会冻伤）、雪地车（外出与返程速度）、
  冰芯钻机（深层采样门槛与质量）、气象传感器（预报信度与采样精度）。
- **天气**：严重度 0–4，随季节推进趋于恶劣；气温、能见度（极佳→白化天）、
  风速三要素共同影响外出风险事件数量、返程体力损耗与样本安全。
- **结局**：
  - 主动撤离（接应抵达）/ 季末（第 14 日）常规撤离 / 全员失能导致站点失联；
  - 评级 **S/A/B/C/D/E**（如"教科书式考察""带血的数据""冰原上的失联档案"），
    依据科学价值、生还人数与撤离方式综合判定。

## 生成的科考档案

结局页面是一份可**打印 / 存为 PDF**、可**下载为 .txt** 的正式档案，包含：
任务概要、每名队员归建状态、完整样本清单（含价值与备注）、关键事件时间线、
行动统计（外出、风险、深挖、检修、会议、遗失样本……）以及依据本局行为生成的
"归档评语"。档案带唯一编号与随机种子。

## 设计说明

- 所有随机数来自可播种的 `mulberry32`，事件权重随天气/地点/设备状态动态变化。
- 数值节奏（无头模拟 43 局）：稳健轮换 + 重视医疗检修的策略可稳定全员生还
  （B–A 级）；只追科学价值的激进打法常以伤亡换取高价值（"带血的数据"）；
  全程保守则平安但评级偏低——安全与价值确实是两种有效取向。
